BD Islamic Messenger — UI Pack
=================================

এই ZIP-এ screenshot অনুযায়ী একটি responsive Islamic Messenger frontend UI আছে।

ফাইল:
- index.html
- styles.css
- app.js
- assets/logo.svg

গুরুত্বপূর্ণ:
এটি আপনার existing Node.js/Express/PostgreSQL/Socket.IO backend মুছে বা পরিবর্তন করে না।
বর্তমানে UI interaction/demo আছে। আপনার existing backend-এর API/Socket.IO endpoint না জেনে
login, permanent history, image/video upload, friend add, block, pin, unread sync ইত্যাদি
বাস্তব backend-এ বাঁধা হয়নি।

পরবর্তী কাজ:
আপনার বর্তমান server.js-এর route/API ও Socket.IO event দেখে এই UI-কে existing backend-এর
সাথে সংযুক্ত করতে হবে। এতে backend নতুন করে শুরু করার প্রয়োজন হবে না।
